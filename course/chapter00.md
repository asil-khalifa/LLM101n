# Chapter 00 — Prerequisites

> Goal: enough Python, PyTorch, and math intuition that Chapters 1–5 feel like fun instead of friction. If you can already write Python comfortably and know what a derivative and a matrix multiply are, skim this and move on.

## Core path (study in order)

1. 🟢 [The Official Python Tutorial](https://docs.python.org/3/tutorial/) — work through at least chapters 1–9 if Python is new to you.
2. 🟢 [CS231n Python/NumPy Tutorial](https://cs231n.github.io/python-numpy-tutorial/) — the exact slice of Python/NumPy that deep learning uses (arrays, broadcasting, vectorized ops).
3. 🟢 [3Blue1Brown — Essence of Linear Algebra](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab) — visual intuition for vectors, matrices, and transformations. Watch at least the first 10 episodes.
4. 🟢 [3Blue1Brown — Essence of Calculus](https://www.youtube.com/playlist?list=PLZHQObOWTQDMsr9K-rj53DwVRMYO3t5Yr) — you mainly need derivatives and the chain rule.
5. 🟢 [3Blue1Brown — Neural Networks](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi) — the best conceptual on-ramp to what a neural net *is* before you build one.
6. 🟡 [PyTorch — Learn the Basics](https://pytorch.org/tutorials/beginner/basics/intro.html) — tensors, datasets, autograd, building a first model. Do this hands-on in a notebook.

## Going deeper (optional)

- 🟡 [Neural Networks and Deep Learning (Michael Nielsen)](http://neuralnetworksanddeeplearning.com/) — free book; the clearest from-first-principles treatment of backprop and why deep learning works.
- 🟡 [Dive into Deep Learning (d2l.ai)](https://d2l.ai/) — interactive textbook with runnable code for nearly everything this course touches.
- 🔴 [Mathematics for Machine Learning](https://mml-book.github.io/) — free book if you want the underlying math done properly.
- 🔴 [Deep Learning (Goodfellow, Bengio, Courville)](https://www.deeplearningbook.org/) — the classic reference text; use as an encyclopedia, not a first read.

## Exercises & projects

- 🟢 [Kaggle Learn: Python](https://www.kaggle.com/learn/python) — short, free, auto-graded Python exercises.
- 🟡 [Tensor Puzzles (Sasha Rush)](https://github.com/srush/Tensor-Puzzles) — 21 puzzles that force you to *really* understand broadcasting and tensor ops. Highly recommended before Chapter 3.
- 🟡 Reimplement a tiny 2-layer network on MNIST in raw NumPy (no framework), using the [Nielsen book chapter 1](http://neuralnetworksanddeeplearning.com/chap1.html) as a guide.
